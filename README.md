# EMOTION BASED MUSIC RECOMMENDATION SYSTEM
## Project overview
- This is the simple project to demonstrate the use of Convultion neural network and computer vision. 
- It consist of around 27000 images for training and around 7000 for testing purpose.
- 3 convolution layer used and two dense layer used for the training. 
- Softmax function is used to introduce non-linearity in model and adam used for controlling learning rate. 
- achieve approx. 60% accuracy on imblanced dataset.
- Integrated model with streamlit for visual interface and hascasdae classifier for frontal face detection.
- Finally, top 15 music recomended to the user.
